# NTFS

## Overview

NTFS (New Technology File System) is the default file system used by modern Windows operating systems.

It stores valuable forensic artifacts that investigators use to reconstruct user activity.

## Learning Objectives

- Understand NTFS architecture
- Learn the Master File Table (MFT)
- Study Alternate Data Streams (ADS)
- Explore timestamps
- Analyze file attributes

## Topics

- MFT
- ADS
- File Attributes
- Journaling
- Metadata

Documentation and practical exercises focused on NTFS forensics.

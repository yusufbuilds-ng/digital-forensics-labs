# Windows Event Viewer

## Overview

Windows Event Viewer is one of the most important tools in Digital Forensics and Incident Response (DFIR). It records events generated by Windows, applications, drivers, and security components, allowing investigators to reconstruct system activity.

## Learning Objectives

- Understand Windows logging
- Explore Event Viewer structure
- Learn event fields
- Analyze Security logs
- Identify Event Levels
- Interpret Event IDs
- Read XML event data

## Topics

- Event Structure
- Event IDs
- Event Levels
- Security Logs
- System Logs
- Application Logs
- XML View

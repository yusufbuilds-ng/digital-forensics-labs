# Windows File System

## Overview

A file system defines how an operating system stores, organizes, retrieves, and manages files on a storage device.

Understanding the Windows file system is essential for digital forensic investigations because every user action leaves traces on disk.

## Learning Objectives

- Learn how files are stored
- Understand file metadata
- Compare FAT32, exFAT, and NTFS
- Explore forensic artifacts
- Understand timestamps

- exFAT
- NTFS
- File Metadata
- File Allocation
